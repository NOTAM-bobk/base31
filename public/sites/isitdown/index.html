How the check works

Three independent probes run in parallel, then the result is combined into one verdict.

01

Direct reachability

Your browser sends a request to the address and times it. If the server answers at all, the host is online; a refused or timed-out connection means it is unreachable.

02

HTTP status

A public CORS proxy fetches the real response code and content type, so you see 200, 301, 404 or 503 rather than a guess.

03

DNS resolution

Cloudflare's DNS-over-HTTPS resolver looks up the A and CNAME records, confirming whether the domain resolves before the request even leaves.

Frequently asked questions

How does this is-it-down check work?
The page sends a live request to the address you enter, times how long the server takes to respond, and cross-checks the HTTP status through a public CORS proxy. DNS is resolved separately through Cloudflare's DNS-over-HTTPS service. Everything runs in your browser.
How accurate is the result?
The result reflects what your browser can reach right now. A down result can also mean the site refuses automated requests, or that your own network or DNS is the problem, so it is worth retrying or testing from another connection.
What do the HTTP status codes mean?
2xx and 3xx mean the server responded normally. 4xx means the server answered but the page is an error — 404 simply means that page is missing, not that the site is down. 5xx means the server itself errored. A timeout with no response means the host could not be reached.
Do you store the sites I check?
No. Checks run entirely in your browser. The optional recent-checks list is saved in your own browser storage and is never sent to a server.
Why does a site I know is online show as down?
Bot protection and firewalls such as Cloudflare or a CAPTCHA can refuse automated requests even while real visitors load the page fine. Your own network, VPN or DNS can also be the cause.
What does a degraded or slow result mean?
It means the server did respond, but took longer than about 1.5 seconds. The site is reachable, yet it may feel down to visitors, and a slow response often comes before an outage.

Checks are made from your own browser, so they show what you can reach. For a view from many locations at once, pair this with a monitoring service.
